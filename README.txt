Contenido:
- index.html: página principal
- assets/: 10 imágenes en el mismo orden del catálogo original

Para publicar gratis:
1. Crea una cuenta en GitHub.
2. Crea un repositorio público (por ejemplo: jailovetv-site).
3. Sube index.html y la carpeta assets.
4. Activa GitHub Pages desde Settings > Pages.
5. Luego conecta tu dominio jailovetv.com en la configuración de Pages.

Antes de publicar:
- Reemplazar "Consultar" por los precios reales.
- Tallas configuradas: 35, 36, 37, 38 y 39.
- WhatsApp configurado: +51 932 241 483.
- Si el dominio final será otro, no cambia la página; solo se configura el dominio.
